Усиливаем контраст сайта

Откройте демо. На сайте обсерватории «Орбита» нажмите «Усилить контраст» и попробуйте заполнить поле имени, перейти по ссылке и нажать кнопку записи. Повторное нажатие на переключатель вернёт бледную HTML-страницу.

В режиме усиления тот же блок #site становится дочерним элементом <canvas content="drawable">. Canvas 2D рисует его через ctx.drawElementImage(), читает кадр через getImageData() и записывает его через putImageData() после преобразования каждого канала RGB по формуле 128 + (v - 207) * 6. Массив Uint8ClampedArray ограничивает результат диапазоном 0–255. Альфа сохраняется.

При отсутствии API переключатель включает контрастную HTML-палитру. Поле имени, ссылка и кнопка записи доступны с клавиатуры. Подпись рядом с переключателем показывает, какой режим активен. Фолбек можно открыть принудительно через ?mode=html.

В Chrome 158 контраст основного текста к фону страницы составил 1,49:1 в HTML и 17,03:1 после обработки общего кадра. Минимальный контраст по WCAG составляет 4,5:1 для обычного текста и 3:1 для крупного. Формула подобрана для палитры демо. WCAG 2.2, критерий 1.4.3

Расширение Chrome

  1. Распакуйте extension.zip.
  2. Откройте chrome://extensions, включите «Режим разработчика» и выберите папку через «Загрузить распакованное расширение».
  3. На обычной веб-странице нажмите «Контраст изображения» в меню расширений и кликните по картинке. Чтобы восстановить её вид, повторите эти два действия. Escape отменяет выбор.

Расширение использует временный доступ к текущей вкладке через activeTab и scripting. Для выбранного img в основном документе расширение пересчитывает каналы RGB по формуле 128 + (v - 128) * 4. Исходные атрибуты src и srcset восстанавливаются при повторном выборе. Изображение сохраняет своё место на странице, альтернативный текст и ссылку, если она есть.

Для картинок с другого origin сервер должен разрешить чтение через CORS. Если браузер не даёт прочитать пиксели или политика страницы блокирует показ результата, расширение показывает причину. Перезагрузка открывает исходное изображение.
