# Ночь в обсерватории · CSS Zen Garden

Откройте `index.html` или запустите локальный HTTP-сервер из корня презентации и откройте `/demos/landings/zen/`. Начальное оформление — Screen Filler. Для прямой ссылки на Wiggles добавьте `?theme=wiggles`.

Обе темы используют одну разметку, включая форму. Переключатель меняет активный CSS и своё состояние `aria-pressed`. Демо-запись подтверждается в браузере, данные остаются в открытой странице.

## Авторы и условия использования

- Классы разметки опираются на [CSS Zen Garden Дэйва Ши](https://www.csszengarden.com/) ([CC BY-NC-SA 3.0](https://creativecommons.org/licenses/by-nc-sa/3.0/)). Текст и поля формы написаны для вымышленного вечера в городской обсерватории.
- [Screen Filler](https://www.csszengarden.com/217/) · Elliot Jay Stocks. `screen.css` импортирует [авторский CSS](https://www.csszengarden.com/217/217.css) из локальной поставки. Сохранены цветовые поля и боковая полоса. Поверх исходных правил настроены кириллица, интервалы и расположение программы и формы. Исходный CSS и адаптация `screen.css` доступны по [CC BY-NC-SA 1.0](https://creativecommons.org/licenses/by-nc-sa/1.0/). В демо используется локальный Golos Text для заголовка, остальные семейства заданы исходной темой с системными запасными шрифтами.
- [Wiggles the Wonderworm](https://www.csszengarden.com/099/) · Joseph Pearson. `wiggles.css` импортирует [авторский CSS](https://www.csszengarden.com/099/099.css) из локальной поставки. Оригинальные бумажные текстуры и две панели комикса используются для оформления. В шапке своего CSS Pearson посвятил стилевой файл и сопровождающие изображения [общественному достоянию](https://creativecommons.org/licenses/publicdomain/). Это заявление автора темы распространяется на использованные здесь изображения. [Общие условия CSS Zen Garden для графики](https://www.csszengarden.com/pages/faq/) требуют разрешения исходного дизайнера.

Лендинг рассчитан на некоммерческий учебный показ. Исходные стили и локальные ресурсы загружаются из `../../zen-garden/`. Шрифт и игровой курсор с таймером в iframe загружаются из `../../../assets/`.
