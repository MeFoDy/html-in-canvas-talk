# Гостевые демо

Полные локальные версии из [репозитория HTML-in-Canvas.dev](https://github.com/en-dash-consulting/html-in-canvas-dot-dev) распространяются с приложенной [лицензией MIT](LICENSE). В презентации сохранены авторская графика, управление, звук и отрисовка. Подключения к Google Fonts заменены локальными файлами в папке fonts. Для японской надписи включены знаки оригинальной сцены. При вводе других знаков браузер может использовать системный японский шрифт.

| Работа | Автор | Оригинал |
| --- | --- | --- |
| Snowfall | Baked Design Studio | [Снег на живой типографике](https://html-in-canvas.dev/demos/snowfall/) |
| Margin Dragon | Baked Design Studio | [Дракон на странице](https://html-in-canvas.dev/demos/margin-dragon/) |
| 3D Room with Live Web Content | En Dash Consulting | [Комната с живыми HTML-поверхностями](https://html-in-canvas.dev/demos/3d-room-live-content/) |

Авторские WebP дракона взяты без перекодирования. Шрифты Inter, EB Garamond, Shippori Mincho и JetBrains Mono распространяются по SIL Open Font License 1.1. Тексты лицензий находятся рядом со шрифтами.

В 3D Room with Live Web Content используется локальная сборка [Three.js 0.158.0](3d-room-live-content/THREE-LICENSE). В слайде камера сразу показывает комнату; кнопка входа включает обзор мышью. Ввод и подтверждение формы на плакате обрабатываются локально. Запасное состояние показывает снимок комнаты и пояснение при отсутствии WebGL или HTML-in-Canvas.
