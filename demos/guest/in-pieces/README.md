# In Pieces

Интерактивная выставка Брайана Джеймса. Описание оригинальной техники и авторства приведено в [статье автора](https://www.smashingmagazine.com/2015/06/the-making-of-in-pieces/).

Локальная сборка [архива siporg](https://github.com/siporg/species-in-pieces) из [зеркала](https://github.com/yusabfa-cyka/species-in-pieces.github.io/tree/main) на Vite 6.0.11 и Sass Embedded 1.83.4 с относительным base. Лицензия восстановленного кода находится в LICENSE. Вариант `?slide` открывает орикса без вступления и с выключенным звуком. Сохранились исходная CSS-анимация треугольников, навигация по видам и материалы экспозиции. Внешние видео открываются по действию зрителя.
